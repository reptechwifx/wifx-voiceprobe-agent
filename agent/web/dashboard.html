HTTP local ne chiffre pas les identifiants. Utilisez un LAN de gestion de confiance et filtrez le port 18441 ; ne le publiez jamais sur Internet. Les échanges Controller restent HTTPS/WSS.
L’identité et les accès sont gérés automatiquement ; aucun token à saisir. Changer de Controller demande une nouvelle adoption. La capacité attribuée par le Controller reste prioritaire. L’identité UUID persistante ne peut pas être modifiée ici.
