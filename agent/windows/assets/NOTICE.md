# Ressources graphiques WIFX

Logo et symbole originaux fournis par le site officiel WIFX et intégrés à la demande de WIFX pour Voice Probe. Les fichiers BMP/ICO sont des conversions de format et de taille de ces originaux, sans nouveau dessin. La marque et les logos restent la propriété de WIFX ; la licence des sources Agent ne confère aucun droit général sur la marque.

Origines et empreintes : `provenance.json`. Le bleu `#1556a3` est relevé dans la feuille de style officielle. La police Web Graphik n’est pas redistribuée ; l’application utilise Segoe UI déjà présent dans Windows. Aucun téléchargement graphique à l’exécution.
