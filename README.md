Ce dépôt contient uniquement l’Agent SIP/RTP WIFX Voice Probe. Agent Bêta 0.9-004, installateurs 1.0.0, PJSIP/PJSUA2 2.16 précompilé.

**Première publication en préparation : aucune installation client n’est encore annoncée comme qualifiée depuis GitHub.** Les commandes seront activées ici après téléchargement et installation réels des artefacts publics.

Les sources originales Agent et outillage sont sous [GPL-3.0-or-later](LICENSE). Les composants tiers conservent leurs licences ; notices et sources correspondantes accompagnent les Releases. Aucun Controller, secret WIFX, historique Git privé ni credential Registry n’est distribué.

Le parcours normal ne compile rien sur la cible, ne nécessite aucun compte GitHub/GitLab et préserve les identités et paramètres lors des mises à jour. Le mot de passe initial est généré localement et remis sur terminal après vérification.
