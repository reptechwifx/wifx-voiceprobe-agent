# Changelog Agent

## Bêta 0.9-004 — installateurs 1.0.0

Première distribution publique préparée : PJSIP/PJSUA2 2.16 précompilé pour Ubuntu24/Python3.12 et Debian12/Python3.11 AMD64 ; image Docker Agent commune à Linux et Synology Intel ; catalogues signés et téléchargements publics GitHub bornés.

Outil permanent de diagnostic/mise à jour, sauvegardes privées, rollback compatible et reprise journalisée. Identifiants initiaux remis sur terminal, identités/adoption/comptes/ports préservés. Aucune planification automatique activée par défaut.

ARM64, Ubuntu22, autres Debian et NAS Synology physiques restent hors qualification de cette livraison.
